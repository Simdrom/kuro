# Kuro's changelog, for users. The setup has it built in and, when it updates Kuro, lists the
# versions after the installed one up to its own. The GitHub release starts with the English
# lines of its version, followed by the commits (git cliff).
#
# "[x.y.z]" starts a version, newest first. The first one is always the version in Cargo.toml,
# the next release: a change users will notice adds its line there in the same commit, like a
# new text in strings.txt. Each line is one change, short and in the user's words (not a commit
# message), in the setup's languages, split by |: en | es | fr | de | it | nb | ko. Like the
# setup's other texts, fr and de say vous and Sie.
#
# The setup's tests check this file. A release fails if its section is empty, and then starts
# an empty one for the next version.
